# MCN-001 Monorepo scaffold and CI — Implementation Plan

> **For agentic workers:** Execute inline task-by-task per superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every lane one set of commands (`make up|down|test|lint|fmt|contracts|e2e`) that work today (skip gracefully where a service isn't scaffolded yet) and CI that runs the right checks per changed path, plus a documented path to branch protection.

**Architecture:** A root `Makefile` fans out to per-service tooling, guarded by "does this service have a build file yet" checks (services are still empty shells until MCN-002/MCN-005). A `scripts/check-contracts.sh` does a light, real validation of the `contracts/` JSON today; MCN-003 replaces it with Spectral/oasdiff/vector-runner. `.github/workflows/ci.yml` uses `dorny/paths-filter` to run lint+test only for changed lanes, plus an always-on contracts job and a Conventional Commit PR-title check. Branch protection is applied via a `gh api` script since it requires a pushed GitHub remote, which does not exist yet.

**Tech Stack:** GNU Make, Bash, Node (JSON validation only, no new deps), GitHub Actions (`dorny/paths-filter@v3`, `amannn/action-semantic-pull-request@v5`), GitHub CLI (`gh`).

**Spec:** `docs/06-user-stories.md` MCN-001 (AC1–5), `docs/07-delivery-plan.md` §7 (branch/PR conventions), root `CLAUDE.md` §3 (command list) and §7 (Definition of Done).

## Ruling: Java version conflict

Root `CLAUDE.md` header says "Java 25"; `docs/02-software-architecture.md` §9 says "Java 21". Per `CLAUDE.md` §2 precedence, the architecture doc outranks the root file — but §9 itself assigns MCN-001 the job of pinning the *actual* version. The dev machine has Corretto 25 (LTS) installed and CLAUDE.md (edited more recently, ADR-adjacent) says 25. **Ruling: pin Java 25 (LTS)**, update `docs/02` §9 in this task, and note the conflict resolved rather than opening a separate doc-fix PR (trivial one-line fix, same PR is fine per reviewer discretion).

## Global Constraints

- Money fields, PCI masking, idempotency etc. are not touched by this story — pure tooling/scaffolding.
- No service code exists yet (`issuer-jpos/`, `gateway-go/`, `web-next/`, `settlement/` only have `CLAUDE.md`). Every Makefile target and CI job must no-op cleanly (exit 0, print a skip line) for a service that isn't scaffolded, not fail the build.
- No new runtime dependencies. Contracts JSON validation uses Node's built-in `JSON.parse` (Node is already required by `web-next`).
- No GitHub remote exists yet. Branch protection is scripted (`gh api`) but only documented as "run once pushed" — do not attempt to call `gh api` against a nonexistent repo.
- PR title = Conventional Commit with story id, per `docs/07-delivery-plan.md` §7 — CI enforces the Conventional Commit *type* prefix (`feat|fix|refactor|docs|test|chore|perf|ci`), not the story id (that's reviewed by humans).

**Files:**

**Interfaces:**

```makefile
.PHONY: up down test lint fmt contracts e2e

COMPOSE := infra/docker-compose.yml

up:
	@if [ -f $(COMPOSE) ]; then docker compose -f $(COMPOSE) up -d; \
	else echo "skip: $(COMPOSE) not scaffolded yet (MCN-002)"; fi

down:
	@if [ -f $(COMPOSE) ]; then docker compose -f $(COMPOSE) down -v; \
	else echo "skip: $(COMPOSE) not scaffolded yet (MCN-002)"; fi

test:
	@for d in issuer-jpos settlement; do \
		if [ -f $$d/build.gradle.kts ] || [ -f $$d/build.gradle ]; then \
			echo "== test $$d =="; (cd $$d && ./gradlew test); \
		else echo "skip: $$d not scaffolded yet"; fi; \
	done
	@if [ -f gateway-go/go.mod ]; then \
		echo "== test gateway-go =="; (cd gateway-go && go test ./...); \
	else echo "skip: gateway-go not scaffolded yet"; fi
	@if [ -f web-next/package.json ]; then \
		echo "== test web-next =="; (cd web-next && npm test); \
	else echo "skip: web-next not scaffolded yet"; fi

lint:
	@for d in issuer-jpos settlement; do \
		if [ -f $$d/build.gradle.kts ] || [ -f $$d/build.gradle ]; then \
			echo "== lint $$d =="; (cd $$d && ./gradlew spotlessCheck); \
		else echo "skip: $$d not scaffolded yet"; fi; \
	done
	@if [ -f gateway-go/go.mod ]; then \
		echo "== lint gateway-go =="; (cd gateway-go && golangci-lint run ./...); \
	else echo "skip: gateway-go not scaffolded yet"; fi
	@if [ -f web-next/package.json ]; then \
		echo "== lint web-next =="; (cd web-next && npm run lint); \
	else echo "skip: web-next not scaffolded yet"; fi

fmt:
	@for d in issuer-jpos settlement; do \
		if [ -f $$d/build.gradle.kts ] || [ -f $$d/build.gradle ]; then \
			echo "== fmt $$d =="; (cd $$d && ./gradlew spotlessApply); \
		else echo "skip: $$d not scaffolded yet"; fi; \
	done
	@if [ -f gateway-go/go.mod ]; then \
		echo "== fmt gateway-go =="; (cd gateway-go && gofmt -l -w .); \
	else echo "skip: gateway-go not scaffolded yet"; fi
	@if [ -f web-next/package.json ]; then \
		echo "== fmt web-next =="; (cd web-next && npm run fmt); \
	else echo "skip: web-next not scaffolded yet"; fi

contracts:
	@./scripts/check-contracts.sh

e2e:
	@if [ -f web-next/package.json ]; then \
		echo "== e2e web-next =="; (cd web-next && npx playwright test); \
	else echo "skip: web-next not scaffolded yet"; fi
```

### Task 2: Contracts validation script

**Files:**
- Create: `scripts/check-contracts.sh`

**Interfaces:**
- Consumes: files under `contracts/` (already committed: `openapi.yaml`, `ws-events.schema.json`, `iso8583/vectors/*.json`, `fixtures/cards.json`).
- Produces: `scripts/check-contracts.sh`, exit 0 on valid JSON/non-empty YAML, exit 1 with a clear message otherwise. Called by `make contracts` (Task 1).

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# ponytail: real checks are JSON-only (no new deps); MCN-003 upgrades this to
# Spectral + oasdiff + full ISO vector round-trip once those tools are wired in.
set -euo pipefail
cd "$(dirname "$0")/.."

fail=0

check_json() {
	local f="$1"
	if ! node -e "JSON.parse(require('fs').readFileSync('$f','utf8'))" 2>/dev/null; then
		echo "INVALID JSON: $f"
		fail=1
	fi
}

if [ ! -s contracts/openapi.yaml ]; then
	echo "MISSING/EMPTY: contracts/openapi.yaml"
	fail=1
fi

check_json contracts/ws-events.schema.json
check_json contracts/fixtures/cards.json
check_json contracts/events/transaction-event.schema.json

shopt -s nullglob
for f in contracts/iso8583/vectors/*.json; do
	check_json "$f"
done

if [ "$fail" -eq 0 ]; then
	echo "contracts: OK"
else
	echo "contracts: FAILED"
fi
exit "$fail"
```

### Task 3: CI workflow with path filters, per-lane jobs, contracts, PR title check

**Files:**
- Create: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: `make lint`/`make test` (Task 1), `make contracts` (Task 2).
- Produces: CI job names `lint-test-iss`, `lint-test-gw`, `lint-test-web`, `lint-test-set`, `contracts`, `pr-title` — referenced by Task 4's branch protection required-checks list.

- [ ] **Step 1: Write the workflow**

```yaml
name: CI

on:
  pull_request:
    branches: [main]
  push:
    branches: [main]

jobs:
  changes:
    runs-on: ubuntu-latest
    outputs:
      iss: ${{ steps.filter.outputs.iss }}
      gw: ${{ steps.filter.outputs.gw }}
      web: ${{ steps.filter.outputs.web }}
      set: ${{ steps.filter.outputs.set }}
    steps:
      - uses: actions/checkout@v4
      - uses: dorny/paths-filter@v3
        id: filter
        with:
          filters: |
            iss:
              - 'issuer-jpos/**'
            gw:
              - 'gateway-go/**'
            web:
              - 'web-next/**'
            set:
              - 'settlement/**'

  lint-test-iss:
    needs: changes
    if: needs.changes.outputs.iss == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Lint + test issuer-jpos
        run: |
          if [ -f issuer-jpos/build.gradle.kts ] || [ -f issuer-jpos/build.gradle ]; then
            cd issuer-jpos && ./gradlew spotlessCheck test
          else
            echo "skip: issuer-jpos not scaffolded yet"
          fi

  lint-test-gw:
    needs: changes
    if: needs.changes.outputs.gw == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Lint + test gateway-go
        run: |
          if [ -f gateway-go/go.mod ]; then
            cd gateway-go && golangci-lint run ./... && go test ./...
          else
            echo "skip: gateway-go not scaffolded yet"
          fi

  lint-test-web:
    needs: changes
    if: needs.changes.outputs.web == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Lint + test web-next
        run: |
          if [ -f web-next/package.json ]; then
            cd web-next && npm ci && npm run lint && npm test
          else
            echo "skip: web-next not scaffolded yet"
          fi

  lint-test-set:
    needs: changes
    if: needs.changes.outputs.set == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Lint + test settlement
        run: |
          if [ -f settlement/build.gradle.kts ] || [ -f settlement/build.gradle ]; then
            cd settlement && ./gradlew spotlessCheck test
          else
            echo "skip: settlement not scaffolded yet"
          fi

  contracts:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: ./scripts/check-contracts.sh

  pr-title:
    if: github.event_name == 'pull_request'
    runs-on: ubuntu-latest
    steps:
      - uses: amannn/action-semantic-pull-request@v5
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          types: |
            feat
            fix
            refactor
            docs
            test
            chore
            perf
            ci
```

Run: `node -e "const fs=require('fs');const yaml=fs.readFileSync('.github/workflows/ci.yml','utf8'); if(!yaml.includes('paths-filter')) process.exit(1); console.log('syntax-plausible, length', yaml.length)"`

### Task 4: Branch protection script (deferred execution — no remote yet)

**Files:**
- Create: `scripts/setup-branch-protection.sh`

**Interfaces:**
- Consumes: CI job names from Task 3 (`contracts`, `pr-title`, and the four `lint-test-*` jobs) as required status checks.
- Produces: a one-shot script to run manually after the first `git push` creates the GitHub remote. Not run by CI or by this plan (no remote exists yet).

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# Run once, after `git remote add origin ...` and the first push, by someone
# with admin on the repo. Requires `gh auth login` already done.
set -euo pipefail

REPO="${1:?usage: scripts/setup-branch-protection.sh <owner>/<repo>}"

gh api "repos/$REPO/branches/main/protection" \
	--method PUT \
	-f "required_status_checks[strict]=true" \
	-f "required_status_checks[contexts][]=contracts" \
	-f "required_status_checks[contexts][]=pr-title" \
	-f "required_status_checks[contexts][]=lint-test-iss" \
	-f "required_status_checks[contexts][]=lint-test-gw" \
	-f "required_status_checks[contexts][]=lint-test-web" \
	-f "required_status_checks[contexts][]=lint-test-set" \
	-f "enforce_admins=true" \
	-f "required_pull_request_reviews[required_approving_review_count]=1" \
	-f "restrictions="

gh api "repos/$REPO" \
	--method PATCH \
	-f "allow_squash_merge=true" \
	-f "allow_merge_commit=false" \
	-f "allow_rebase_merge=false"

echo "Branch protection + squash-only merge set on $REPO"
```

Run: `chmod +x scripts/setup-branch-protection.sh && ./scripts/setup-branch-protection.sh; echo "exit=$?"`
Expected: `usage: scripts/setup-branch-protection.sh <owner>/<repo>`, `exit=1`.

