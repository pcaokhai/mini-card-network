# MCN-202 Gateway connection manager — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans with superpowers:test-driven-development. Worktree `../mcn-worktrees/gw-202-connection-manager`, branch `feat/MCN-202-connection-manager`. Requires MCN-101 merged (codec) and MCN-005-GW merged (config/obs/api skeleton).

**Goal:** `gateway-go` connects to the issuer, signs on, echoes every 60s, detects 3 consecutive echo failures as DOWN, reconnects with backoff+jitter, signs on again, and persists link state + a `network_event` row per change — first real database usage for this service.

**Architecture:** `internal/isonet` owns a single `Supervisor` state machine (`DISCONNECTED → CONNECTED → SIGNED_ON → DOWN → ...`) driven by a loop: connect → sign-on → echo ticker → on 3 failures, mark DOWN, close, backoff-sleep, reconnect. `internal/store` gets its first real tables (`link_state`, `network_event`) via goose migrations and pgx (no sqlc yet — the query set is tiny; sqlc setup is deferred to the first story with a nontrivial query surface, per YAGNI, and recorded as a ruling below). The codec's `Pack`/`Unpack` (MCN-101) build/parse the 0800 sign-on/echo/sign-off frames over a length-prefixed TCP connection (`internal/isonet/framer.go`).

**Tech Stack:** Go 1.24, `pgx/v5`, `goose` (migrations), Testcontainers-go (Postgres), Toxiproxy Go client (for the integration test against the already-running `infra/docker-compose.yml` Toxiproxy), `golang.org/x/sync/errgroup`.

**Spec:** `docs/03-iso8583-interface-spec.md` §1 (framing), §7.1 (sign-on/echo), `docs/02-software-architecture.md` §7.6/§9 (`mcn_link_up` metric), `docs/05-data-model.md` §3/§5, `docs/06-user-stories.md` MCN-202, `gateway-go/CLAUDE.md`.

## Rulings

- **No sqlc this story**: `gateway-go/CLAUDE.md` names `pgx + sqlc` for `internal/store`, but MCN-202's query surface is 4 statements (upsert link status, insert event, list links, list events). Hand-written `pgx` queries in a small `LinkRepository` are simpler and the generated-code machinery (sqlc.yaml, `make generate` wiring) has nothing to generate *from* yet without a larger schema. sqlc is introduced in the first story that needs it for real query-count reasons (likely MCN-303's `tran_log`) — recorded here so it isn't silently forgotten, not because it's wrong to add later.
- **`link_state` schema**: `link_state(id BIGSERIAL PK, endpoint TEXT NOT NULL UNIQUE, status TEXT NOT NULL CHECK (status IN ('DISCONNECTED','CONNECTED','SIGNED_ON','DOWN')), last_echo_at TIMESTAMPTZ, last_echo_latency_ms INTEGER, p99_latency_ms INTEGER, in_flight INTEGER NOT NULL DEFAULT 0, updated_at TIMESTAMPTZ NOT NULL DEFAULT now())`. `endpoint` value this sprint is the fixed string `"issuer"` (only link that exists until the switch, Sprint 10). Matches `contracts/openapi.yaml`'s `Link` schema field-for-field (`linkId`→endpoint here, `status`, `lastEchoAt`, `p99LatencyMs`, `inFlight`).
- **`network_event` schema**: `network_event(id BIGSERIAL PK, occurred_at TIMESTAMPTZ NOT NULL DEFAULT now(), severity TEXT NOT NULL CHECK (severity IN ('INFO','WARN','ERROR')), easy_text TEXT NOT NULL, technical_text TEXT NOT NULL)` — matches `docs/05-data-model.md` §4's `network_event(id, occurred_at, severity, easy_text, technical_text)` exactly (that one row already has a concrete column list, unlike `acquirer_link`/`link_state`).
- **Migration number**: first `gateway-go` migration, `migrations/00001_link_state_and_network_event.sql` (goose numbers its own files; `00001` since none exist yet).
- **Backoff**: 1s base, 30s cap, full jitter (`rand(0, min(cap, base*2^attempt))`), matching AC2's "backoff 1–30s + full jitter" and the pattern already established for the SAF worker's own backoff rule in `gateway-go/CLAUDE.md` (2s/60s there — different numbers, same algorithm shape; MCN-202 uses the numbers this story's AC states, not the SAF worker's).
- **Echo interval**: 60s per AC1; 3 consecutive failures (timeout or connection error) before declaring DOWN, per AC2.
- **Toxiproxy integration test (AC4)** requires the real `infra/docker-compose.yml` stack running (`make up`) — it is skipped (not failed) when Toxiproxy's admin API isn't reachable, so `go test` still passes in environments without Docker, but the real assertion only fires with the stack up. Document this clearly in the test's own skip message.

package isonet

import (
	"encoding/binary"
	"fmt"
	"io"
)

const maxFrameSize = 4096 // docs/03 §1

// WriteFrame writes a 2-byte big-endian length header followed by payload.
func WriteFrame(w io.Writer, payload []byte) error {
	if len(payload) > maxFrameSize {
		return fmt.Errorf("frame too large: %d bytes (max %d)", len(payload), maxFrameSize)
	}
	header := make([]byte, 2)
	binary.BigEndian.PutUint16(header, uint16(len(payload)))
	if _, err := w.Write(header); err != nil {
		return fmt.Errorf("write frame header: %w", err)
	}
	if _, err := w.Write(payload); err != nil {
		return fmt.Errorf("write frame payload: %w", err)
	}
	return nil
}

// ReadFrame reads one length-prefixed frame.
func ReadFrame(r io.Reader) ([]byte, error) {
	header := make([]byte, 2)
	if _, err := io.ReadFull(r, header); err != nil {
		return nil, fmt.Errorf("read frame header: %w", err)
	}
	size := binary.BigEndian.Uint16(header)
	if size > maxFrameSize {
		return nil, fmt.Errorf("frame too large: %d bytes (max %d)", size, maxFrameSize)
	}
	payload := make([]byte, size)
	if _, err := io.ReadFull(r, payload); err != nil {
		return nil, fmt.Errorf("read frame payload: %w", err)
	}
	return payload, nil
}
```

package isonet

import (
	"math/rand/v2"
	"time"
)

// Backoff computes full-jitter exponential backoff: delay = random(0, min(cap, base*2^attempt)).
type Backoff struct {
	Base time.Duration
	Cap  time.Duration
}

func (b Backoff) ceiling(attempt int) time.Duration {
	d := b.Base
	for i := 0; i < attempt; i++ {
		d *= 2
		if d >= b.Cap {
			return b.Cap
		}
	}
	return d
}

// Delay returns a jittered delay for the given attempt number (0-indexed).
func (b Backoff) Delay(attempt int) time.Duration {
	ceiling := b.ceiling(attempt)
	if ceiling <= 0 {
		return 0
	}
	return time.Duration(rand.Int64N(int64(ceiling)))
}
```

func (r *LinkRepository) SetStatus(ctx context.Context, endpoint, status string) error {

		`UPDATE link_state SET status = $2, updated_at = now() WHERE endpoint = $1`, endpoint, status)

func (r *LinkRepository) RecordEcho(ctx context.Context, endpoint string, latencyMs int) error {
	_, err := r.pool.Exec(ctx,
		`UPDATE link_state SET last_echo_at = now(), last_echo_latency_ms = $2, updated_at = now() WHERE endpoint = $1`,
		endpoint, latencyMs)
	return err
}

func (r *LinkRepository) Get(ctx context.Context, endpoint string) (Link, error) {
	var l Link
	err := r.pool.QueryRow(ctx,
		`SELECT endpoint, status, last_echo_at, last_echo_latency_ms, p99_latency_ms, in_flight FROM link_state WHERE endpoint = $1`,
		endpoint).Scan(&l.Endpoint, &l.Status, &l.LastEchoAt, &l.LastEchoLatencyMs, &l.P99LatencyMs, &l.InFlight)
	return l, err

	_, err := r.pool.Exec(ctx,
		`INSERT INTO network_event (severity, easy_text, technical_text) VALUES ($1, $2, $3)`,
		severity, easyText, technicalText)
	return err
}

func (r *LinkRepository) ListEvents(ctx context.Context, limit int) ([]NetworkEvent, error) {
	rows, err := r.pool.Query(ctx,
		`SELECT id, occurred_at, severity, easy_text, technical_text FROM network_event ORDER BY occurred_at DESC LIMIT $1`, limit)
	if err != nil {
		return nil, err
	}

	for rows.Next() {
		var e NetworkEvent
		if err := rows.Scan(&e.ID, &e.OccurredAt, &e.Severity, &e.EasyText, &e.TechnicalText); err != nil {
			return nil, err
		}
		events = append(events, e)
	}
	return events, rows.Err()
}

```go
package isonet

import (
	"context"
	"net"
	"time"

	"github.com/mcn/gateway-go/internal/iso8583"
)

// LinkStore is the persistence port the supervisor needs; internal/store implements it.
type LinkStore interface {
	SetStatus(ctx context.Context, endpoint, status string) error
	RecordEcho(ctx context.Context, endpoint string, latencyMs int) error
	RecordEvent(ctx context.Context, severity, easyText, technicalText string) error
}

// Config configures one Supervisor. Zero EchoTimeout means EchoInterval is used as the timeout.
type Config struct {
	Addr             string
	EchoInterval     time.Duration
	EchoTimeout      time.Duration
	EchoFailureLimit int
	Backoff          Backoff
}

const endpointName = "issuer" // v1 has exactly one link; the switch (Sprint 10) adds more.

// Supervisor keeps one link healthy: connect, sign on, echo, detect failure, reconnect.
type Supervisor struct {
	cfg   Config
	store LinkStore
	stan  int
}

func NewSupervisor(cfg Config, store LinkStore) *Supervisor {
	if cfg.EchoTimeout == 0 {
		cfg.EchoTimeout = cfg.EchoInterval
	}
	if cfg.Backoff == (Backoff{}) {
		cfg.Backoff = Backoff{Base: time.Second, Cap: 30 * time.Second}
	}
	return &Supervisor{cfg: cfg, store: store}
}

// Run supervises the link until ctx is cancelled.
func (s *Supervisor) Run(ctx context.Context) error {
	attempt := 0
	for {
		select {
		case <-ctx.Done():
			return nil
		default:
		}
		err := s.runOnce(ctx)
		if ctx.Err() != nil {
			return nil
		}
		_ = err // connection lifecycle errors are expected (reconnect loop); logging is the caller's job via obs
		_ = s.store.SetStatus(ctx, endpointName, "DOWN")
		_ = s.store.RecordEvent(ctx, "WARN", "Link to issuer is down", "reconnecting with backoff")
		delay := s.cfg.Backoff.Delay(attempt)
		attempt++
		select {
		case <-ctx.Done():
			return nil
		case <-time.After(delay):
		}
	}
}

// runOnce connects, signs on, and echoes until the link fails or ctx is cancelled.
func (s *Supervisor) runOnce(ctx context.Context) error {
	conn, err := net.Dial("tcp", s.cfg.Addr)
	if err != nil {
		return err
	}
	defer conn.Close()
	_ = s.store.SetStatus(ctx, endpointName, "CONNECTED")

	if err := s.signOn(conn); err != nil {
		return err
	}
	_ = s.store.SetStatus(ctx, endpointName, "SIGNED_ON")
	_ = s.store.RecordEvent(ctx, "INFO", "Link to issuer is up", "signed on")

	failures := 0
	ticker := time.NewTicker(s.cfg.EchoInterval)
	defer ticker.Stop()
	for {
		select {
		case <-ctx.Done():
			_ = s.signOff(conn)
			return nil
		case <-ticker.C:
			latency, err := s.echo(conn)
			if err != nil {
				failures++
				if failures >= s.cfg.EchoFailureLimit {
					return err
				}
				continue
			}
			failures = 0
			_ = s.store.RecordEcho(ctx, endpointName, int(latency.Milliseconds()))
		}
	}
}

func (s *Supervisor) nextStan() string {
	s.stan++
	return padSTAN(s.stan)
}

func padSTAN(n int) string {
	digits := []byte("000000")
	for i := len(digits) - 1; n > 0; i-- {
		digits[i] = byte('0' + n%10)
		n /= 10
	}
	return string(digits)
}

func (s *Supervisor) sendReceive(conn net.Conn, mti string, fields map[int]string) (map[int]string, error) {
	packed, err := iso8583.Pack(mti, fields)
	if err != nil {
		return nil, err
	}
	if err := WriteFrame(conn, []byte(packed)); err != nil {
		return nil, err
	}
	resp, err := ReadFrame(conn)
	if err != nil {
		return nil, err
	}
	_, respFields, err := iso8583.Unpack(string(resp))
	return respFields, err
}

func (s *Supervisor) signOn(conn net.Conn) error {
	fields, err := s.sendReceive(conn, "0800", map[int]string{7: nowDE7(), 11: s.nextStan(), 70: "001"})
	if err != nil {
		return err
	}
	if fields[39] != "00" {
		return errRC(fields[39])
	}
	return nil
}

func (s *Supervisor) signOff(conn net.Conn) error {
	_, err := s.sendReceive(conn, "0800", map[int]string{7: nowDE7(), 11: s.nextStan(), 70: "002"})
	return err
}

func (s *Supervisor) echo(conn net.Conn) (time.Duration, error) {
	start := time.Now()
	if err := conn.SetDeadline(start.Add(s.cfg.EchoTimeout)); err != nil {
		return 0, err
	}
	defer conn.SetDeadline(time.Time{})
	fields, err := s.sendReceive(conn, "0800", map[int]string{7: nowDE7(), 11: s.nextStan(), 70: "301"})
	if err != nil {
		return 0, err
	}
	if fields[39] != "00" {
		return 0, errRC(fields[39])
	}
	return time.Since(start), nil
}
```
