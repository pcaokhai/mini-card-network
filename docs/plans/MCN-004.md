# MCN-004 Web application shell — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Tasks 3–7 touch disjoint files after Task 2 and may be dispatched with superpowers:dispatching-parallel-agents; Task 8 (Storybook) runs last. Worktree `../mcn-worktrees/web-004`, branch `feat/MCN-004-web-shell`. Requires MCN-001 merged. Contracts from the documentation pack are already in `contracts/`.

**Goal:** A Next.js console shell matching the design: sidebar with 9 entries in 3 groups, header with search, link pill and Easy/Expert toggle, design and motion tokens with reduced-motion support, Vietnamese/English messages, MSW mock mode from the OpenAPI contract, and Storybook.

**Architecture:** App Router with a `(console)` route group holding the shell layout and one placeholder page per screen. Shared layers under `src/shared/` (ui, state, navigation, motion, i18n, api). next-intl without locale routing (cookie `NEXT_LOCALE`, default `vi`). Display mode in a persisted Zustand store. API types and MSW handlers generated from `contracts/openapi.yaml` and committed; CI checks they are current.

**Tech stack:** Next.js (App Router, version resolved by `create-next-app@latest`), TypeScript strict, Tailwind CSS v4, next-intl, Zustand, Motion, TanStack Query, Zod, openapi-typescript, openapi-fetch, MSW + msw-auto-mock, Vitest + Testing Library, Storybook (nextjs-vite).

## Understanding

MCN-004 AC (docs/06 §E0): (1) layout per design: 9 entries / 3 groups, header with search, link pill, mode toggle; (2) toggle persists and switches `<Term>` labels app-wide without layout shift; (3) design + motion tokens, reduced motion → fades; (4) vi and en messages, vi default; (5) MSW mock mode with generated handlers; Storybook with design-system components.

This plan was executed end to end in a sandbox on 2026-09-21 with `create-next-app@latest` resolving to Next.js 16.3: 8 unit tests passed, `tsc --noEmit`, `eslint` and `next build` were clean, and `storybook build` succeeded. Browser-based story tests could not run there (no Playwright browsers); run them locally in Task 8.

`src/i18n/request.ts`
```ts
import { cookies } from "next/headers";
import { getRequestConfig } from "next-intl/server";

export const LOCALES = ["vi", "en"] as const;
export type Locale = (typeof LOCALES)[number];
export const DEFAULT_LOCALE: Locale = "vi";

function isLocale(value: string | undefined): value is Locale {
  return value !== undefined && (LOCALES as readonly string[]).includes(value);
}

/** MCN-004-AC4: locale from the NEXT_LOCALE cookie, Vietnamese by default (no locale in URLs). */
export default getRequestConfig(async () => {
  const cookieLocale = (await cookies()).get("NEXT_LOCALE")?.value;
  const locale: Locale = isLocale(cookieLocale) ? cookieLocale : DEFAULT_LOCALE;
  return { locale, messages: (await import(`../../messages/${locale}.json`)).default };
});
```

/** Renders a domain term in the current display mode; the hint explains it in the current locale. */

"use client";

import { useSyncExternalStore } from "react";
import { duration, ease } from "@/shared/motion/tokens";

const QUERY = "(prefers-reduced-motion: reduce)";

function subscribe(onChange: () => void): () => void {
  const mql = window.matchMedia(QUERY);
  mql.addEventListener("change", onChange);
  return () => mql.removeEventListener("change", onChange);
}

export function usePrefersReducedMotion(): boolean {
  return useSyncExternalStore(subscribe, () => window.matchMedia(QUERY).matches, () => false);
}

/** MCN-004-AC3: every animation asks this hook; reduced motion becomes a short fade. */
export function useMotionPreference() {
  const reduced = usePrefersReducedMotion();
  const enter = reduced
    ? { initial: { opacity: 0 }, animate: { opacity: 1 }, transition: { duration: duration.reducedFade } }
    : { initial: { opacity: 0, y: 8 }, animate: { opacity: 1, y: 0 }, transition: { duration: duration.base, ease: ease.out } };
  return { reduced, enter } as const;
}
