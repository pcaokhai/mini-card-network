# MCN-204 Network API and WebSocket events — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans with superpowers:test-driven-development. Worktree `../mcn-worktrees/gw-204-network-api`, branch `feat/MCN-204-network-api`. Requires MCN-202 and MCN-203 merged (needs `store.LinkRepository` and `isonet.Mux`/`Supervisor` for real echo/sign-on triggers).

**Goal:** Expose the network state over REST (`GET /v1/links`, `GET /v1/network/events`, `POST /v1/links/{endpoint}/echo`, `POST /v1/links/{endpoint}/sign-on`, `POST /v1/links/{endpoint}/sign-off`) and push `link.status`/`network.event` over the existing WebSocket hub (MCN-005-GW) so the console updates live.

**Architecture:** `internal/api/network.go` adds chi routes backed by `store.LinkRepository` (read paths) and a new `isonet.Manager` (thin wrapper the API calls for manual echo/sign-on/sign-off, since MCN-202's `Supervisor` owns the live connection and manual triggers must go through the same connection, not open a second one). `internal/ws/hub.go` (already exists from MCN-005-GW) gets two new broadcast methods; `Supervisor` calls them at every status/event transition, replacing the earlier direct-only `store` calls with a small "publish to both store and hub" helper.

**Tech Stack:** Go 1.24, chi, the existing WS hub from MCN-005-GW, `kin-openapi` request/response validation (already wired per MCN-103's Lab API pattern).

**Spec:** `contracts/openapi.yaml` (`/v1/links`, `/v1/network/events`, `/v1/links/{endpoint}/{action}` — already present from the doc pack, confirmed no new contract PR needed), `contracts/ws-events.schema.json` (`link.status`, `network.event` — already present), `docs/04-api-contract.md`, `docs/06-user-stories.md` MCN-204.

## Rulings

- **Manual echo/sign-on/sign-off reuse the live connection, not a second one.** `Supervisor` (MCN-202) owns the only TCP connection to the issuer. A manual "echo now" button can't dial its own socket — it must ask the running `Supervisor` to send one immediately. `Supervisor` gets a small `TriggerEcho(ctx) error` / `TriggerSignOn(ctx) error` / `TriggerSignOff(ctx) error` method set that the API calls; internally these just call the same `s.echo`/`s.signOn`/`s.signOff` the reconnect loop already uses, guarded by a mutex so a manual trigger and the automatic 60s ticker never race on the same `Mux`. If `Supervisor` isn't currently `SIGNED_ON` (e.g. mid-reconnect), the trigger returns a typed error mapped to HTTP 409.
- **`endpoint` path param is always `"issuer"` this sprint** (only link that exists, per MCN-202's ruling) — the API validates it and returns 404 for anything else, which is intentionally strict now and trivially extended once the switch (Sprint 10) adds more links.
- **WS event shape** matches `contracts/ws-events.schema.json` exactly: `{"type":"link.status","endpoint":"issuer","status":"SIGNED_ON","at":"<RFC3339>"}` and `{"type":"network.event","severity":"INFO","easyText":"...","technicalText":"...","occurredAt":"<RFC3339>"}` — read the actual schema file before implementing the struct tags, don't assume field names.

```go
package api

import (
	"context"
	"encoding/json"
	"net/http"

	"github.com/go-chi/chi/v5"

	"github.com/mcn/gateway-go/internal/store"
)

// LinkReader is the read-side port network.go needs; store.LinkRepository satisfies it.
type LinkReader interface {
	Get(ctx context.Context, endpoint string) (store.Link, error)
	ListEvents(ctx context.Context, limit int) ([]store.NetworkEvent, error)
}

// LinkTrigger is the manual-action port; isonet.Supervisor satisfies it (Task 2).
type LinkTrigger interface {
	TriggerEcho(ctx context.Context) error
	TriggerSignOn(ctx context.Context) error
	TriggerSignOff(ctx context.Context) error
}

const issuerEndpoint = "issuer"

func MountNetwork(r chi.Router, reader LinkReader, trigger LinkTrigger) {
	r.Get("/v1/links", func(w http.ResponseWriter, req *http.Request) {
		link, err := reader.Get(req.Context(), issuerEndpoint)
		if err != nil {
			http.Error(w, err.Error(), http.StatusInternalServerError)
			return
		}
		writeJSON(w, http.StatusOK, []store.Link{link})
	})

	r.Get("/v1/network/events", func(w http.ResponseWriter, req *http.Request) {
		events, err := reader.ListEvents(req.Context(), 100)
		if err != nil {
			http.Error(w, err.Error(), http.StatusInternalServerError)
			return
		}
		writeJSON(w, http.StatusOK, events)
	})

	r.Post("/v1/links/{endpoint}/echo", triggerHandler(trigger, func(ctx context.Context, t LinkTrigger) error { return t.TriggerEcho(ctx) }))
	r.Post("/v1/links/{endpoint}/sign-on", triggerHandler(trigger, func(ctx context.Context, t LinkTrigger) error { return t.TriggerSignOn(ctx) }))
	r.Post("/v1/links/{endpoint}/sign-off", triggerHandler(trigger, func(ctx context.Context, t LinkTrigger) error { return t.TriggerSignOff(ctx) }))
}

func triggerHandler(trigger LinkTrigger, call func(context.Context, LinkTrigger) error) http.HandlerFunc {
	return func(w http.ResponseWriter, req *http.Request) {
		if chi.URLParam(req, "endpoint") != issuerEndpoint {
			http.Error(w, "unknown endpoint", http.StatusNotFound)
			return
		}
		if err := call(req.Context(), trigger); err != nil {
			http.Error(w, err.Error(), http.StatusConflict)
			return
		}
		w.WriteHeader(http.StatusAccepted)
	}
}

func writeJSON(w http.ResponseWriter, status int, body any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(body)
}
```

Check: if `store.Link`/`store.NetworkEvent`'s existing Go field names don't already carry the right JSON tags for the OpenAPI schema (e.g. `Endpoint`→`"linkId"` per the MCN-202 ruling note), add `json:"..."` tags to those structs in `internal/store/links.go` now rather than duplicating a separate API-layer DTO — YAGNI, one struct is enough until the shapes actually diverge.

```go
var errNotSignedOn = errors.New("link is not signed on")

// TriggerEcho sends an out-of-band echo now, using the live connection's Mux if signed on.
// Guarded by triggerMu so a manual trigger never races the automatic echo ticker.
func (s *Supervisor) TriggerEcho(ctx context.Context) error {
	s.triggerMu.Lock()
	defer s.triggerMu.Unlock()
	if s.mux == nil {
		return errNotSignedOn
	}
	_, err := s.echo(ctx)
	return err
}

func (s *Supervisor) TriggerSignOn(ctx context.Context) error {
	s.triggerMu.Lock()
	defer s.triggerMu.Unlock()
	if s.mux == nil {
		return errNotSignedOn
	}
	return s.signOn(ctx, nil)
}

func (s *Supervisor) TriggerSignOff(ctx context.Context) error {
	s.triggerMu.Lock()
	defer s.triggerMu.Unlock()
	if s.mux == nil {
		return errNotSignedOn
	}
	return s.signOff(ctx, nil)
}
```
