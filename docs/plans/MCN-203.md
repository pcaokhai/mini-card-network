# MCN-203 Message multiplexer (MUX) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans with superpowers:test-driven-development. Worktree `../mcn-worktrees/gw-203-mux`, branch `feat/MCN-203-mux`. Requires MCN-202 merged (this story extends `internal/isonet` with a shared request/response correlator the Supervisor's connection will route through).

**Goal:** A single `Mux` correlates outbound ISO 8583 requests to their responses by (DE 11 STAN, DE 7 transmission date/time), enforces a per-request timeout, exposes a `late_response` hook/metric, and is safe under concurrent load (1000 concurrent requests, `-race` clean).

**Architecture:** `internal/isonet/mux.go` owns a `map[key]chan response` guarded by a mutex; `Send(ctx, mti, fields) (response, error)` allocates a STAN via a shared atomic counter (replacing `Supervisor`'s private one from MCN-202 — noted as a ruling below), registers a pending entry, writes the frame, and blocks on the channel or `ctx`/timeout. A single reader goroutine per connection (owned by `Mux.Serve(conn)`) reads frames and dispatches to the matching pending entry, or to a "late" handler if none is found (already timed out or reversed).

**Tech Stack:** Go 1.24, `context`, `sync`, `golang.org/x/sync/errgroup`, `testify`, `go test -race`.

**Spec:** `docs/03-iso8583-interface-spec.md` §5 (matching key: STAN + DE7), `docs/06-user-stories.md` MCN-203, `docs/02-software-architecture.md` §7 (MUX component), `gateway-go/CLAUDE.md` (unknown-outcome → reversal rule, though the reversal/SAF worker itself belongs to a later story — MCN-203 only owns detection and the `late_response` metric, not queuing the 0420).

## Rulings

- **STAN ownership moves from `Supervisor` to `Mux`.** MCN-202 gave `Supervisor` a private STAN counter because MUX didn't exist yet. Now that both sign-on/echo traffic and (future) financial traffic share one wire, one counter must issue every STAN to avoid collisions. `Supervisor` is refactored to call `Mux.Send` instead of its own `sendReceive`, removing `nextStan`/`padSTAN` from `supervisor.go`. This is a small refactor task (Task 4 below), not a new feature.
- **Timeout default:** 30s per request unless the caller specifies otherwise (`docs/03` doesn't give a global number; use the same 30s ceiling as MCN-202's backoff cap as a consistent, documented default — callers can override per-call via `context.WithTimeout`).
- **Late response definition:** a frame arrives whose (STAN, DE7) key is not in the pending map. This happens when a response arrives after the caller's `ctx` timeout already returned an error. MCN-203 only detects and counts this (`mcn_late_response_total`); it does not yet trigger a reversal — that's explicitly out of scope this story (SAF/reversal is a later sprint per the delivery plan) and is called out so no one assumes it's silently handled.

```go
package isonet

import (
	"context"
	"fmt"
	"io"
	"strconv"
	"sync"
	"sync/atomic"

	"github.com/mcn/gateway-go/internal/iso8583"
)

type muxKey struct {
	stan string
	de7  string
}

// Mux correlates one connection's outbound requests to their inbound responses by (STAN, DE7).
type Mux struct {
	conn    io.ReadWriter
	writeMu sync.Mutex

	pendingMu sync.Mutex
	pending   map[muxKey]chan map[int]string

	stan int64

	onLateResponse func(mti string, fields map[int]string)
}

func NewMux(conn io.ReadWriter) *Mux {
	return &Mux{conn: conn, pending: make(map[muxKey]chan map[int]string)}
}

// NextSTAN issues the next 6-digit STAN for this connection (docs/03 §5: shared per-link counter).
func (m *Mux) NextSTAN() string {
	n := atomic.AddInt64(&m.stan, 1)
	return fmt.Sprintf("%06d", n%1000000)
}

// Send writes a request and blocks for its correlated response, or returns ctx's error on timeout/cancel.
func (m *Mux) Send(ctx context.Context, mti string, fields map[int]string) (map[int]string, error) {
	key := muxKey{stan: fields[11], de7: fields[7]}
	ch := make(chan map[int]string, 1)

	m.pendingMu.Lock()
	m.pending[key] = ch
	m.pendingMu.Unlock()
	defer func() {
		m.pendingMu.Lock()
		delete(m.pending, key)
		m.pendingMu.Unlock()
	}()

	packed, err := iso8583.Pack(mti, fields)
	if err != nil {
		return nil, fmt.Errorf("pack request: %w", err)
	}

	m.writeMu.Lock()
	err = WriteFrame(m.conn, []byte(packed))
	m.writeMu.Unlock()
	if err != nil {
		return nil, fmt.Errorf("write request: %w", err)
	}

	select {
	case resp := <-ch:
		return resp, nil
	case <-ctx.Done():
		return nil, ctx.Err()
	}
}

// Serve reads frames from the connection and dispatches them to pending Send calls, or to
// onLateResponse when no pending request matches (the caller already timed out).
func (m *Mux) Serve(ctx context.Context) error {
	for {
		if ctx.Err() != nil {
			return nil
		}
		payload, err := ReadFrame(m.conn)
		if err != nil {
			return err
		}
		mti, fields, err := iso8583.Unpack(payload)
		if err != nil {
			continue // malformed frame from the wire; drop and keep serving
		}
		key := muxKey{stan: fields[11], de7: fields[7]}

		m.pendingMu.Lock()
		ch, ok := m.pending[key]
		m.pendingMu.Unlock()

		if !ok {
			if m.onLateResponse != nil {
				m.onLateResponse(mti, fields)
			}
			continue
		}
		ch <- fields
	}
}

var _ = strconv.Itoa // placeholder import guard removed once unused imports are trimmed
```

### Task 3: Concurrency proof — 1000 concurrent requests, `-race` clean (AC4)

**Files:** `internal/isonet/mux_race_test.go`

- [ ] **Step 1: Write the test**

```go
package isonet

import (
	"context"
	"fmt"
	"net"
	"sync"
	"testing"

	"github.com/stretchr/testify/require"

	"github.com/mcn/gateway-go/internal/iso8583"
)

func TestMux_handles1000ConcurrentRequests__MCN_203_AC4(t *testing.T) {
	client, server := net.Pipe()
	defer client.Close()
	defer server.Close()

	// Echo server: read every frame, answer with the same fields plus RC 00.
	go func() {
		for {
			payload, err := ReadFrame(server)
			if err != nil {
				return
			}
			_, fields, err := iso8583.Unpack(payload)
			if err != nil {
				continue
			}
			fields[39] = "00"
			packed, err := iso8583.Pack("0810", fields)
			if err != nil {
				continue
			}
			if err := WriteFrame(server, []byte(packed)); err != nil {
				return
			}
		}
	}()

	mux := NewMux(client)
	ctx, cancel := context.WithCancel(context.Background())
	defer cancel()
	go func() { _ = mux.Serve(ctx) }()

	const n = 1000
	var wg sync.WaitGroup
	errs := make([]error, n)
	for i := 0; i < n; i++ {
		wg.Add(1)
		go func(i int) {
			defer wg.Done()
			de7 := fmt.Sprintf("0101%06d", i)
			_, err := mux.Send(context.Background(), "0800", map[int]string{7: de7, 11: mux.NextSTAN(), 70: "301"})
			errs[i] = err
		}(i)
	}
	wg.Wait()

	for i, err := range errs {
		require.NoErrorf(t, err, "request %d failed", i)
	}
}
```

Note: each goroutine uses a distinct DE7 value (`0101%06d`) so that concurrently-issued STANs (which wrap at 1,000,000 per `NextSTAN`) can never collide on the same `muxKey` even under high concurrency — this is why the key is (STAN, DE7) per the spec, not STAN alone.

```go
func (s *Supervisor) runOnce(ctx context.Context) error {
	conn, err := net.Dial("tcp", s.cfg.Addr)
	if err != nil {
		return err
	}
	defer conn.Close()
	_ = s.store.SetStatus(ctx, endpointName, "CONNECTED")

	mux := NewMux(conn)
	mux.OnLateResponse(func(string, map[int]string) { obs.LateResponseTotal.Inc() })
	serveCtx, cancelServe := context.WithCancel(ctx)
	defer cancelServe()
	serveErr := make(chan error, 1)
	go func() { serveErr <- mux.Serve(serveCtx) }()

	s.mux = mux
	if err := s.signOn(ctx, conn); err != nil {
		return err
	}
	_ = s.store.SetStatus(ctx, endpointName, "SIGNED_ON")
	_ = s.store.RecordEvent(ctx, "INFO", "Link to issuer is up", "signed on")

	failures := 0
	ticker := time.NewTicker(s.cfg.EchoInterval)
	defer ticker.Stop()
	for {
		select {
		case <-ctx.Done():
			_ = s.signOff(ctx, conn)
			return nil
		case err := <-serveErr:
			return err
		case <-ticker.C:
			latency, err := s.echo(ctx)
			if err != nil {
				failures++
				if failures >= s.cfg.EchoFailureLimit {
					return err
				}
				continue
			}
			failures = 0
			_ = s.store.RecordEcho(ctx, endpointName, int(latency.Milliseconds()))
		}
	}
}
```

```go
func (s *Supervisor) signOff(ctx context.Context, _ net.Conn) error {

func (s *Supervisor) echo(ctx context.Context) (time.Duration, error) {
	start := time.Now()
	sendCtx, cancel := context.WithTimeout(ctx, s.cfg.EchoTimeout)
	defer cancel()
	fields, err := s.mux.Send(sendCtx, "0800", map[int]string{7: nowDE7(), 11: s.mux.NextSTAN(), 70: "301"})
	if err != nil {
		return 0, err
	}
	if fields[39] != "00" {
		return 0, errRC(fields[39])
	}
	return time.Since(start), nil
```
