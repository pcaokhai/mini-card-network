# MCN-201 Issuer ISO server and network management — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans with superpowers:test-driven-development. Worktree `../mcn-worktrees/iss-201-network`, branch `feat/MCN-201-issuer-iso-server`. Requires MCN-102 merged (packager) and MCN-005-ISS merged (Q2 skeleton, health/metrics beans).

**Goal:** The issuer accepts ISO 8583 TCP connections on :8000 via a jPOS `QServer`, answers sign-on/sign-off/echo (0800/DE70 001/002/301) with 0810 RC 00, rejects financial requests on a signed-off link with RC 91, and handles malformed messages per docs/03 §1 (0x10/0x30 RC 30 when the MTI is readable, otherwise close the connection).

**Architecture:** `QServer` + `NACChannel` (2-byte length header framing, per docs/03 §1) using the generated `iso87ascii.xml` packager (MCN-102). `ISORequestListener` only enqueues to a `TransactionManager` (jPOS's own queueing) — never blocks the channel thread. Two participants: `ParseAndValidate` (malformed-message handling) and `HandleNetworkManagement` (sign-on/sign-off/echo + link-state persistence to `acquirer_link`). A third minimal participant, `RejectUnsignedFinancial`, runs before any future financial participant (none exist yet — this sprint only wires the network-management path; financial requests just get RC 91 unconditionally on any link, signed-on or not, until MCN-302 adds real authorization. Rule: financial handling doesn't exist yet, so RC 91 is correct for every 01xx/02xx message this sprint by definition, not a shortcut).

**Tech Stack:** jPOS 3.0.1 Q2/TransactionManager, PostgreSQL 16 (Flyway migration, first one for `issuer-jpos`), HikariCP, JUnit 5 + AssertJ, Testcontainers.

**Spec:** `docs/03-iso8583-interface-spec.md` §1 (transport/framing), §7.1 (network management, RC 91 rule), `docs/05-data-model.md` §2/§5 (migration rules, `acquirer_link` table name reserved), `docs/06-user-stories.md` MCN-201, `issuer-jpos/CLAUDE.md`.

## Rulings

- **`acquirer_link` schema** (not specified column-by-column anywhere in `docs/05`, so this plan defines it per `docs/05` §3's stated conventions): `acquirer_link(id BIGINT PK, acquirer_id TEXT NOT NULL, status TEXT NOT NULL CHECK (status IN ('DISCONNECTED','CONNECTED','SIGNED_ON','DOWN')), last_sign_on_at TIMESTAMPTZ, last_echo_at TIMESTAMPTZ, created_at TIMESTAMPTZ NOT NULL DEFAULT now(), updated_at TIMESTAMPTZ NOT NULL DEFAULT now(), UNIQUE(acquirer_id))`. One row per counterparty; v1 has exactly one row (`970499`, the lab acquirer ID from `docs/03` §3).
- **Migration number**: this is the first `issuer-jpos` Flyway migration — `V1__acquirer_link.sql`. (Settlement/gateway reserve their own independent sequences per `docs/05` §5 rule 1 — no cross-service coordination needed since each has its own schema/DB per ADR-004.)
- **Malformed-message handling**: "MTI is readable" means the first 4 bytes parsed as digits successfully (mirrors `iso8583.CodecError{Code: "INVALID_MTI"}`'s condition in the Go codec, MCN-101) — if MTI parses, respond with the corresponding 0x10/0x30 response MTI and RC 30; anything else (framing error, unpackable bitmap/fields) closes the connection and logs at WARN with the raw bytes masked via `IsoLogMasker` (MCN-102).
- **RC 91 scope this sprint**: every MTI class `01`/`02` (financial) message gets RC 91 unconconditionally, since no authorization participant exists yet (MCN-302 replaces this). This is not a stub to revisit for correctness — it's the spec-correct behavior for "no financial capability wired yet."

```java
package io.mcn.issuer.adapter.persistence;

import java.sql.SQLException;
import java.util.Optional;
import javax.sql.DataSource;

public final class JdbcAcquirerLinkRepository implements AcquirerLinkRepository {
  private final DataSource dataSource;

  public JdbcAcquirerLinkRepository(DataSource dataSource) {
    this.dataSource = dataSource;
  }

  @Override
  public void upsertStatus(String acquirerId, String status) {
    String sql =
        "INSERT INTO acquirer_link (acquirer_id, status, updated_at) VALUES (?, ?, now()) "
            + "ON CONFLICT (acquirer_id) DO UPDATE SET status = excluded.status, updated_at = now(), "
            + "last_sign_on_at = CASE WHEN excluded.status = 'SIGNED_ON' THEN now() ELSE acquirer_link.last_sign_on_at END";
    try (var conn = dataSource.getConnection();
        var stmt = conn.prepareStatement(sql)) {
      stmt.setString(1, acquirerId);
      stmt.setString(2, status);
      stmt.executeUpdate();
    } catch (SQLException e) {
      throw new IllegalStateException("upsertStatus failed for " + acquirerId, e);
    }
  }

  @Override
  public Optional<String> findStatus(String acquirerId) {
    String sql = "SELECT status FROM acquirer_link WHERE acquirer_id = ?";
    try (var conn = dataSource.getConnection();
        var stmt = conn.prepareStatement(sql)) {
      stmt.setString(1, acquirerId);
      try (var rs = stmt.executeQuery()) {
        return rs.next() ? Optional.of(rs.getString("status")) : Optional.empty();
      }
    } catch (SQLException e) {
      throw new IllegalStateException("findStatus failed for " + acquirerId, e);
    }
  }
}
```

```java
package io.mcn.issuer.adapter.iso;

import java.io.IOException;
import java.net.ServerSocket;
import java.net.Socket;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import org.jpos.iso.ISOException;
import org.jpos.iso.ISOMsg;
import org.jpos.iso.channel.NACChannel;
import org.jpos.iso.packager.GenericPackager;

/** Accepts NACChannel connections and dispatches each message to ParseAndValidate. Framework code, testable without Q2. */
public final class IsoServer {
  private ServerSocket serverSocket;
  private final ExecutorService acceptor = Executors.newSingleThreadExecutor();
  private final ExecutorService workers = Executors.newCachedThreadPool();
  private volatile boolean running;

  public int start(int port) throws IOException {
    serverSocket = new ServerSocket(port);
    running = true;
    acceptor.submit(this::acceptLoop);
    return serverSocket.getLocalPort();
  }

  private void acceptLoop() {
    while (running) {
      try {
        Socket socket = serverSocket.accept();
        workers.submit(() -> handle(socket));
      } catch (IOException e) {
        if (running) {
          // log and continue accepting; a single accept failure must not kill the server
        }
      }
    }
  }

  private void handle(Socket socket) {
    try {
      var channel = new NACChannel();
      channel.setPackager(new GenericPackager("src/dist/cfg/iso87ascii.xml"));
      channel.setSocket(socket);
      while (running && !socket.isClosed()) {
        ISOMsg request = channel.receive();
        ISOMsg response = new ParseAndValidate().handle(request);
        if (response != null) {
          channel.send(response);
        } else {
          break; // malformed beyond MTI: close per AC4
        }
      }
    } catch (ISOException | IOException e) {
      // malformed/unreadable message or connection error: close the socket (AC4)
    } finally {
      try {
        socket.close();
      } catch (IOException ignored) {
        // already closing
      }
    }
  }

  public void stop() {
    running = false;
    try {
      if (serverSocket != null) serverSocket.close();
    } catch (IOException ignored) {
      // shutting down
    }
    acceptor.shutdownNow();
    workers.shutdownNow();
  }
}
```

```java
package io.mcn.issuer.adapter.iso;

import io.mcn.issuer.adapter.persistence.AcquirerLinkRepository;
import org.jpos.iso.ISOException;
import org.jpos.iso.ISOMsg;

/** Sign-on/sign-off/echo per docs/03 §7.1; anything else (financial, on this sprint's build) gets RC 91. */
public final class HandleNetworkManagement {
  private static final String LAB_ACQUIRER_ID = "970499"; // docs/03 §3

  private final AcquirerLinkRepository links;

  public HandleNetworkManagement(AcquirerLinkRepository links) {
    this.links = links;
  }

  public ISOMsg handle(ISOMsg request) throws ISOException {
    String mtiClass = request.getMTI().substring(0, 2);
    ISOMsg response = (ISOMsg) request.clone();
    response.setResponseMTI();

    if ("08".equals(mtiClass)) {
      String de70 = request.getString(70);
      switch (de70) {
        case "001" -> links.upsertStatus(LAB_ACQUIRER_ID, "SIGNED_ON");
        case "002" -> links.upsertStatus(LAB_ACQUIRER_ID, "DISCONNECTED");
        case "301" -> { /* echo: no state change, just RC 00 */ }
        default -> {
          response.set(39, "30"); // unsupported network management code
          return response;
        }
      }
      response.set(39, "00");
      return response;
    }

    if ("01".equals(mtiClass) || "02".equals(mtiClass)) {
      response.set(39, "91"); // no financial capability wired yet this sprint (ruling)
      return response;
    }

    response.set(39, "30");
    return response;
  }
}
```
