# R1 — Sprint 1: "Learners can dissect any MCN-87A message"

Version 1.0 · 2026-09-22 · Sprint 1 (E1 — Message codec and Message Lab), per `docs/07-delivery-plan.md` §2–3

Sprint goal achieved: both backend hosts (gateway, issuer) pack/unpack byte-identical ISO 8583 wire messages from the same spec file, the gateway exposes a Lab API to decode/encode/sample any message, and the web console has a real Message Lab screen — no more placeholder. This release adds the `lab/*` slice (S1) behind flag `FF_S1_MESSAGE_LAB`. It still ships no business/authorization logic — that starts in Sprint 3 (E3).

## How to test

### 1. Codec correctness (no server needed)

```bash
# Go codec: 4 golden vectors round-trip byte-identical, 5 invalid vectors return typed
# errors with the DE number, 60s fuzz with zero panics, cross-checked against moov-io/iso8583
make -C gateway-go test          # CGO_ENABLED=0 if your machine has a broken Xcode SDK linker
                                  # (see "Known gaps" below) — CI always runs the real -race build

# jPOS packager: the same 4 golden vectors, generated from the same packager-spec.yaml
cd issuer-jpos && ./gradlew spotlessApply build
```

Both should report the same 4 vectors passing — `contracts/iso8583/vectors/*.json` is the single source of truth both codecs are checked against.

### 2. Lab API (gateway, no infra needed — pure in-memory)

```bash
cd gateway-go && go run ./cmd/gateway
# in another shell:
curl -s -X POST localhost:8080/v1/lab/messages/decode \
  -d '{"raw":"0800822000000000000004000000000000000921073300000200301"}' | python3 -m json.tool
curl -s localhost:8080/v1/lab/messages/samples | python3 -m json.tool
```

Expect `decode` to return `mti`, `primaryBitmap`, an ordered `segments` array, and a `fields` array with `de`/`easyName`/`technicalName`/`format`/`value` per data element; `samples` to return the 4 golden vectors as labeled samples. Try a PAN-bearing message (`contracts/iso8583/vectors/0200-purchase-chip-pin.json`'s `packed` value) and confirm DE 2's `value` is masked (`970436******4417`) — masking applies to the raw segment text too, not just the decoded value.

### 3. Message Lab screen (web console, mock mode — no gateway needed)

```bash
cd web-next && NEXT_PUBLIC_API_MOCKS=true pnpm dev
```

Open `http://localhost:3000/lab/message`, paste a raw message (e.g. the `0800` sample above), and check:
- the message renders as coloured segments, an 8×8 bitmap grid, and a field table
- clicking any segment, bitmap cell, or table row highlights the same data element everywhere
- the header's Easy/Expert toggle changes field names live and shows/hides the Format column
- selecting the MTI shows its 4-digit breakdown; selecting DE 22 shows the entry-mode meaning (e.g. "051" → "Chip + PIN")
- with a message that sets a DE ≥ 65 (any `0420`/`0430` reversal vector), a second "secondary bitmap" tab appears

### 4. Integration checkpoint (real gateway, not mocks)

```bash
make up   # brings up the whole platform, gateway included
# in web-next: NEXT_PUBLIC_API_MOCKS=false pnpm dev
```

Paste a raw message in the running console and confirm it's decoded by the real `gateway-go` Lab API, not MSW — same visual result as step 3, proving the OpenAPI contract holds end to end.

### 5. Per-lane commands (also run in CI, per changed path)

```bash
make -C gateway-go lint test    # gofmt, golangci-lint v2, go test -race (44 tests)
make -C issuer-jpos test        # ./gradlew spotlessApply build equivalent (via Makefile: spotlessCheck + test)
make -C web-next lint test      # eslint, tsc, generated-code freshness, 20 vitest cases across 11 files
make contracts                  # unaffected by this sprint's codec work, still green
```

## Known gaps fixed while building this (worth knowing before Sprint 2)

- **Go `go generate` runs with cwd = the directory of the file holding the directive**, not the module root — a relative path bug (`../contracts/...` vs the correct `../../../contracts/...`) in the codec generator.
- **golangci-lint's gocyclo** flagged `Pack` (14) and `Unpack` (26) over the project's limit of 10; refactored into small named helpers rather than raising the threshold.
- **moov-io/iso8583 v0.26.1** needs three non-obvious things to cross-check correctly: field 1 must be a real `field.Bitmap` (not a generic field); Bitmap/Hex fields need `encoding.BytesToASCIIHex` (MCN-87A's wire format is ASCII hex *text*, not raw bytes, despite the package's own doc example suggesting `encoding.Binary`); padding must only apply to *fixed*-length fields, never to LL/LLL-prefixed ones.
- **jPOS 3.0.1's `GenericPackager`** needs DE 1 as an explicit `<isofield class="...IFA_BITMAP">` entry (auto-extends to the secondary bitmap); `IFA_ALPHA` doesn't exist in this version (`IF_CHAR` does); no built-in class packs an LLL-prefixed ASCII-hex binary field correctly, so a small custom `IFA_LLLHEXBINARY` field packager was written, combining jPOS's own `AsciiHexInterpreter` with `AsciiPrefixer.LLL`.
- **Root `.gitignore`'s `dist/` rule** was silently excluding `issuer-jpos/src/dist/`, a real committed source tree per jPOS convention, not a build artifact — fixed with a scoped negation.
- **PAN can leak through raw hex, not just the decoded value** — the Lab API's `Segments[].Text` for DE 2 needed the same masking as `Fields[].value`; this was caught in review before merge, not after.
- **`contracts/openapi.yaml` had a real YAML bug**: an unquoted comma inside a flow-mapping `description` field broke `kin-openapi`'s spec loader (the comma reads as a second key-value separator). Fixed in PR #16, verified with the actual failing tool (`Validate()` now succeeds).
- **Local-machine-only**: `-race` and full binary linking for `gateway-go/cmd/gateway` fail on this dev Mac due to a broken Xcode CommandLineTools SDK (`tapi error: malformed file`) — unrelated to the code; verified with `CGO_ENABLED=0` locally, `-race` runs for real on CI's Linux runners.
